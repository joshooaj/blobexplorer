Blob Explorer turns a public Azure Blob Storage container into a browsable file portal. One Docker container, no account, no credentials — just a URL.

Advanced search

Search runs across the whole container from any folder, matching the full path (folders and file name together), case-insensitively. Five styles:

smart client
Plain text: any substring of the path. Spaces are ignored, so smartclient still matches “Smart Client”.
*.exe
Wildcards: * matches any run of characters, ? a single one. Used when the query contains * or ?, e.g. hotfix?, 20?? R?*/*.exe.
^…
Regex: start the query with ^ and everything after it is a JavaScript regex, e.g. ^XProtect Smart Client/Versions/2026.*\.exe$. The ^ itself is part of the pattern, so it anchors at the start of the path.
/…
Also regex, with a leading slash: the first / is stripped and the rest is the pattern (write no closing slash), e.g. /\.exe$. If a regex fails to compile, the query falls back to a plain text search.
~sofilnt
Fuzzy: the characters must appear in order, gaps allowed, so sofilnt finds “some file name.txt”. Best-scoring matches come first; ~~ searches for a literal leading tilde. (Pinned pattern favorites stay regex-based; fuzzy applies to typed and pinned search queries.)
